## 📦 WORKSPACE PACKAGES

1. @tapestry/mobile (apps/mobile)
   - Cross-platform Expo app
   - Supports iOS, Android, and Web
   - Uses expo-router for navigation
   - Example: Counter component with shared UI

2. @tapestry/web (apps/web)
   - Next.js 14 web application
   - App Router (React Server Components)
   - Example: Counter component with CSS modules

3. @tapestry/shared (packages/shared)
   - Shared TypeScript types
   - Utility functions
   - Used by all apps/services

4. @tapestry/ui (packages/ui)
   - React Native UI components
   - Cross-platform (mobile & web)
   - Components: Button, Card

5. @tapestry/config (packages/config)
   - Shared ESLint configurations
   - Shared TypeScript configurations
   - Reusable across workspaces

6. @tapestry/api (services/api)
   - Express.js REST API
   - TypeScript support
   - Endpoints: /api/health, /api/users

- pnpm clean          # Clean all build artifacts

### Mobile App (apps/mobile)

- pnpm web            # Run in web browser

### Web App (apps/web)
- pnpm dev            # Start dev server (localhost:3000)
- pnpm build          # Build for production
- pnpm start          # Start production server

### API Service (services/api)
- pnpm dev            # Start API dev server (localhost:3001)
- pnpm build          # Build API
- pnpm start          # Start production API

## 🚦 BUILD PIPELINE (Turborepo)

build:
  - Runs in dependency order
  - Caches outputs
  - Parallel execution where possible

lint:
  - Runs ESLint on all packages
  - No dependency order needed

type-check:
  - Checks TypeScript types
  - Depends on build for workspace packages

dev:
  - Starts all dev servers
  - Persistent tasks
  - No caching
